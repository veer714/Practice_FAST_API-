# Patient Management API

A simple Patient Management REST API built using FastAPI for learning and practicing backend development concepts.

This project is part of my FastAPI learning journey. I will continue adding new features and improving the API as I learn more about FastAPI, databases, authentication, testing, and deployment.

## Features

- Home endpoint
- About endpoint
- View all patients
- View patient by ID
- Sort patients by height or BMI
- Query Parameters
- Path Parameters
- HTTP Exception Handling
- JSON-based data storage

---

## Tech Stack

- Python
- FastAPI
- Uvicorn
- JSON
